**11. المصادقة (Authentication)**
*   **POST /login**
    ```json
    {
        "message": "Login successful",
        "access_token": "your_api_token_here",
        "token_type": "bearer",
        "user": {
            "id": 1,
            "name": "User Name",
            "email": "user@example.com",
            "roles": [
                {
                    "id": 1,
                    "name": "role_name",
                    "pivot": {
                        "user_id": 1,
                        "role_id": 1
                    },
                    "permissions": [
                        {
                            "id": 1,
                            "name": "permission_name_1"
                        }
                        {
                            "id": 2,
                            "name": "permission_name_2"
                        }
                    ]
                }
            ],
            "permissions": [
                "permission_name_1",
                "permission_name_2"
            ]
        }
    }
    ```
    *   **Invalid Credentials / Validation Errors**
        ```json
        {
            "message": "Invalid credentials"
        }
        ```
        OR
        ```json
        {
            "errors": {
                "email": [
                    "The email field is required."
                ]
            }
        }
        ```

**12. تعديل دور المستخدم (Update User Role)**
*   **POST /users (Create User)**
    ```json
    {
        "message": "User created successfully",
        "user": {
            "name": "user",
            "email": "user@gmail.com",
            "id": 6,
            "roles": [
                {
                    "id": 4,
                    "name": "writer-theses",
                    "pivot": {
                        "user_id": 6,
                        "role_id": 4
                    }
                }
            ]
        }
    }
    ```
    *   **Validation Errors**
        ```json
        {
            "errors": {
                "email": [
                    "The email has already been taken."
                ]
            }
        }
        ```
*   **PUT /users/{user} (Update User)**
    ```json
    {
        "message": "User updated successfully",
        "user": {
            "id": 2,
            "name": "Updated User Name",
            "email": "updated_email@example.com",
            "email_verified_at": null,
            "roles": [
                {
                    "id": 1,
                    "name": "new_role_name",
                    "pivot": {
                        "user_id": 2,
                        "role_id": 1
                    }
                }
            ]
        }
    }
    ```
    *   **Validation Errors**
        ```json
        {
            "errors": {
                "email": [
                    "The email has already been taken."
                ]
            }
        }
        ```
*   **DELETE /users/{user} (Delete User)**
    ```json
    {
        "message": "User deleted successfully"
    }
    ```
    *   **Cannot delete last super admin**
        ```json
        {
            "message": "Cannot delete the last super admin user."
        }
        ```
